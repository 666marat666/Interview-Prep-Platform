Issue summary (Feb 1, 2026)
===========================

Current issue
-------------
Local Go API will not start because the `go` command is not available on the
current PATH for this terminal session.
When running `npm run dev:api`, it fails with:
  "go : The term 'go' is not recognized..."
This prevents the API from listening on http://localhost:4000, so Vite's proxy
to `/api/*` fails with ECONNREFUSED.

Fix steps
---------
1) Ensure Go is on PATH in the current terminal session.
   - Open a new terminal after installing Go, or add Go to PATH.
   - If Go is installed but not visible, set PATH to include its bin folder.

2) In repo root, run:
   - `go mod tidy`
   This generates go.sum and downloads `google.golang.org/genai`.

3) Run local mock stack (one command):
   - `npm run dev:mock`

If Go is installed but still not on PATH, update PATH or modify
`scripts/dev-mock.mjs` to use the absolute path to go.exe.
